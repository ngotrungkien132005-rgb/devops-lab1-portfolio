Git là gì? Tại sao phải dùng Git?

Git là hệ thống quản lý phiên bản phân tán (Distributed Version Control System) phổ biến nhất hiện nay. Nó giúp bạn theo dõi sự thay đổi của các file, ghi lại lịch sử và dễ dàng phối hợp làm việc cùng nhiều người khác trên cùng một dự án.

Mẹo nhớ: Hãy coi Git như nút "Save Game" (Lưu trò chơi) siêu cấp. Khi code bị lỗi, bạn có thể dễ dàng tải lại bản "Save" trước đó mà không sợ mất dữ liệu.

3 Trạng thái cốt lõi của Git

  • Working Directory: Nơi bạn đang trực tiếp chỉnh sửa file.
  • Staging Area: Khu vực chờ, nơi chứa các file đã được chuẩn bị để commit.
  • Repository: Kho lưu trữ chính thức, nơi ghi lại an toàn lịch sử các commit.

Các Câu Lệnh Git Cơ Bản

Khởi tạo dự án

git init: Biến một thư mục bình thường thành một kho lưu trữ Git (Local Repository).

git init

git clone: Sao chép một kho lưu trữ có sẵn trên mạng (như GitHub) về máy tính.

git clone <url>

Lưu trữ thay đổi

git add: Đưa file vào khu vực chờ (Staging Area). Dùng dấu chấm . để thêm tất cả.

git add .

git commit: Chốt (lưu) các thay đổi từ khu vực chờ vào Repository kèm theo lời nhắn.

git commit -m "Thêm tính năng đăng nhập"

Đồng bộ dữ liệu

git push: Đẩy các commit từ máy tính (Local) lên máy chủ (Remote/GitHub).

git push origin main

git pull: Kéo và gộp các thay đổi mới nhất từ máy chủ về máy tính của bạn.

git pull origin main

Quản lý nhánh (Branch)

git branch: Liệt kê, tạo hoặc xóa nhánh. Nhánh giúp bạn làm tính năng mới mà không ảnh hưởng code chính.

git branch ten_nhanh_moi

git checkout: Chuyển đổi sang một nhánh khác để làm việc.

git checkout ten_nhanh
