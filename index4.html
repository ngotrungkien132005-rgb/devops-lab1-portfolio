GitHub Actions

Nền tảng CI/CD (Continuous Integration & Continuous Deployment) mạnh mẽ, được tích hợp trực tiếp ngay trong kho lưu trữ GitHub của bạn.

Học cấu trúc cơ bản Làm trắc nghiệm

GitHub Actions là gì?

GitHub Actions cho phép bạn tự động hóa, tùy chỉnh và thực thi các quy trình phát triển phần mềm (software development workflows) ngay trong kho lưu trữ (repository) của mình.

Bạn có thể khám phá, tạo và chia sẻ các hành động (actions) để thực hiện bất kỳ công việc nào, bao gồm cả CI/CD. Chẳng hạn, bạn có thể thiết lập quy trình tự động chạy test mỗi khi có người push code, hoặc tự động deploy lên server khi có bản release mới.

5 Thành Phần Cốt Lõi

1. Workflows

Một quy trình tự động hóa có thể thiết lập được. Workflows được định nghĩa bằng file YAML đặt trong thư mục .github/workflows của repository.

2. Events

Sự kiện kích hoạt (trigger) để workflow bắt đầu chạy. Ví dụ: khi có lệnh push, mở một pull request, hoặc chạy theo lịch (cron).

3. Jobs

Một tập hợp các bước (steps) thực thi trên cùng một máy chủ (runner). Mặc định các jobs chạy song song, nhưng có thể thiết lập phụ thuộc nhau.

4. Steps

Một nhiệm vụ đơn lẻ trong một Job. Nó có thể là một lệnh shell (chạy script) hoặc gọi đến một Action có sẵn.

5. Runners

Máy chủ (server) cài sẵn ứng dụng GitHub Actions runner. Có thể dùng máy ảo do GitHub cấp (Ubuntu, Windows, macOS) hoặc tự host.

Ví Dụ Cấu Hình YAML

Dưới đây là một Workflow CI đơn giản dành cho dự án Node.js. Nó sẽ tự động kích hoạt mỗi khi có code mới được đẩy (push) lên nhánh main.

.github/workflows/node.js.yml 
name: Node.js CI

on:
  push:
    branches: [ "main" ]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    # Lấy mã nguồn từ Repository xuống Runner
    - uses: actions/checkout@v3
    
    # Cài đặt môi trường Node.js
    - name: Use Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18.x'
        
    # Chạy các lệnh script
    - run: npm ci
    - run: npm run build
    - run: npm test
